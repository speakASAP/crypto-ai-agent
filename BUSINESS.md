# Business: crypto-ai-agent
>
> ⚠️ IMMUTABLE BY AI.

## Goal

AI-powered cryptocurrency portfolio management platform with real-time price tracking, AI predictions, price alerts, and Telegram notifications.

## Constraints

- AI must never execute real trades without explicit user confirmation
- API keys (Binance, etc.) managed in .env only — never logged
- Price alerts must not spam users (max 1/hour per coin per user)
- Trading suggestions are advisory only — no auto-execution

## Success Metrics

- Portfolio tracking accuracy > 99.9%
- Alert delivery < 5s from trigger
- User retention MoM
